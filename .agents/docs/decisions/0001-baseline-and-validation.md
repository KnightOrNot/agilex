# ADR 0001：Python 3.12/uv 基线与验收边界

- 状态：已接受（来源为用户 2026-11-05 的明确指令及现有实现）。
- 背景：先在 main 发布子模块布局迁移，再在 dev 验证 Python 3.12；随后用户授权合并、推送并删除 dev。
- 决定：根和五个子模块以 main 为基线，全部使用 uv 管理的 Python 3.12 和独立 frozen 环境；子模块位于 third-party，发布子模块后再发布父 gitlink。
- 结果：主项目基线 `926e513`；其他提交与同步证据见 [testing](../stages/testing.md)。不自动恢复长期 dev，不自动升级 gitlink。
- 验收边界：此前第 1–4 项有软件、模拟及真机只读证据；这些证据不能证明物理运动、完整方向/端点、相机开流或持续吞吐通过。用户后来自行运行的退出日志也不能扩展为完整第 5/6 项通过。
- 定位容差：2026-10-20 用户授权浏览器应用 `position_tolerance_deg=1.1`；代码 `src/agilex_controller/control.py::move_js` 仍默认 1.0°，CLI 不隐式读取 collection 的 1.1°。此次只修正文档范围，不改变任何运动参数。
- 相关：原 CLAUDE 中部分段落声称所有入口共用 1.1°，与当前调用不同，本轮不再沿用该概括。历史诊断见 [复盘](../reviews/history-2026-10.md)。
