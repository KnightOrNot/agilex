# ADR 0004：HAL 服务化架构与分阶段迁移

状态：设计接受；P1 软件验证通过，准备 dev 异机待测快照，真机验收未完成。日期：2026-11-11。

用户在多轮评审 [v3.3 架构基线](../../../ARCHITECTURE_v3.3.md) 后授权开始实施。目标为适配不同主手、从臂、相机和新增传感器；契约、runtime、驱动与导出器各自承担明确职责。

本决定允许按架构路线逐步重排运行时代码，取代 conventions.md 中「不因规范化重排运行时代码」对本次有目的迁移的限制；旧入口在验收前保留。两种记录模式、独立子模块与可配置的 1.0° 容差是目标设计，P1 不修改现有真机路径或现有容差。

新契约包先在独立本地仓库开发；用户随后明确授权先提交 dev 供异机真机实验，并创建 agilex-contract 远端。本地项目名、目录、Python 导入统一为 agilex-contract / agilex_contract，子仓 dev 先推送，父仓再固定其 gitlink。该分发例外见 git.md，不能解释为真机已通过或稳定版发布。原有五个 gitlink 不变，adapters/GELLO 的移除与重命名按 P7 执行。

故障默认报错停止；已有回零反馈/CAN/状态保护继续有效。断令后的硬件行为仍为 unverified。P1/P2 仿真可先行；依赖硬件的 P0/P3+ 验收保留原授权与证据门槛。

执行范围与验收见 [P1 计划](../specs/architecture-p1-plan.md)。设计冻结不等于实现、发布或硬件验收完成。
